# Free Browser Daily Games

A small, hand-checked list of free daily puzzle and mini games that run in a browser.
Every entry was opened and checked: free to play, no download, no account needed to start.

> Fan-made games below are independent projects and are not affiliated with Nintendo, The Pokémon Company, Rockstar Games or Take-Two.

## Rare-answer trivia (Krillion-style)

Games where you name a valid answer and score more for the ones fewer people would think of.

| Game | What it is |
| --- | --- |
| [Krillion](https://krillion.io/) | Daily dive of 7 general-trivia prompts; rarer valid answers score deeper. |
| [Krillion Pokemon pack](https://krillion.cc/krillion-pokemon/) | Random 7-prompt dives drawn from a pack of about a hundred Pokémon prompts. |
| [PokéKrill](https://pokekrill.com/) | Pokémon questions that also cover trainers, moves and places; one daily journey plus practice. |
| [PokéKrillion](https://www.pokekrillion.com/) | Typed Pokémon version: 7 prompts, 20 seconds each, daily and practice dives. |
| [Pokémon Krillion](https://pokemonkrillion.com/) | Pokémon edition with a no-typing Quick Pick mode (pick from 6 cards, 3 are decoys) plus a typed Classic mode; daily and practice. |

## Most-common-answer games (Noillirk / Crowdict-style)

Guess the answer most people would give.

| Game | What it is |
| --- | --- |
| [Noillirk](https://noillirk.com/) | Guess the answer most people would give; daily set plus practice. |
| [Noillirk Answers](https://noillirkanswers.com/) | Daily hints and the ranked top-five answers for each prompt, hidden until you choose to reveal them. |

## Where to find more daily games

Directories that list many daily browser games.

| Game | What it is |
| --- | --- |
| [Best Daily Games](https://bestdaily.games/) | Browse daily browser puzzles by category, read rules, and open the original games. My Daily saves a personal play list in the browser. |
| [Dailies Play](https://dailiesplay.com/) | Directory of daily browser games with rules, reset times and spoiler-free dated answer pages; free, no account. |
| [Dle Hunt](https://dlehunt.com/) | Directory of daily puzzle games with ratings. |
| [itch.io – daily tag](https://itch.io/games/tag-daily) | Indie games tagged "daily". |
| [Listdle](https://listdle.com/) | Large list of daily games like Wordle, by category. |

## Contributing
Open a pull request adding one entry to `data/games.yml`: name, homepage link, one factual sentence. The game must be free, playable in a browser and must not require an account to start. Run `python scripts/build_readme.py` before committing.
